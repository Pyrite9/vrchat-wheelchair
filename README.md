# Pyrite9 Wheelchair — VRChat wheelchair gimmick

**日本語** · **English** · **한국어**

A free wheelchair gimmick for VRChat avatars. Drop the prefab onto any humanoid avatar — it fits itself to the avatar at build time (size, seat width, sitting height, footrests).
VRChat アバター用の無料の車椅子ギミックです。ヒューマノイドのアバターにプレハブを入れるだけで、ビルド時に体型に合わせて自動で調整されます。
VRChat 아바타용 무료 휠체어 기믹입니다. 휴머노이드 아바타에 프리팹을 넣기만 하면 빌드할 때 체형에 맞춰 자동 조정됩니다.

## Install / 導入 / 설치

1. Add **Modular Avatar** and **lilToon** to your project (VCC / ALCOM).
2. Import `Pyrite9_Wheelchair_v*.unitypackage` (or copy `Assets/Pyrite9/Wheelchair/` from this repository, keeping the `.meta` files).
3. Drag `Assets/Pyrite9/Wheelchair/Wheelchair.prefab` onto your avatar.
4. Check with Build & Test, then Build & Publish.

Details: [README_en](Assets/Pyrite9/Wheelchair/README_en.md) · [README_jp](Assets/Pyrite9/Wheelchair/README_jp.md) · [README_ko](Assets/Pyrite9/Wheelchair/README_ko.md)

## Requirements / 動作環境 / 필요한 것

PC only · Unity 2022.3 · VRChat SDK Avatars 3.x · Modular Avatar (NDMF) · lilToon · humanoid avatar
Tested: Unity 2022.3.22f1 / VRChat SDK 3.10.5 / Modular Avatar 1.18.7 / NDMF 1.14.8 / lilToon 2.3.4
